# QUEST ambient audio

Primary ambience: `20090610_0_ambience.ogg` by nille, hosted on Wikimedia Commons.
The recording is described as forest ambience with birds, insects and wind and is released into the public domain.

Source: https://commons.wikimedia.org/wiki/File:20090610_0_ambience.ogg

The game falls back to `forest-ambience-fallback.wav` if the remote recording is unavailable.
The fallback is generated locally for offline play.
